# Elegguacita's | R&R

A Spanish-first, bilingual static hair and beauty site concept built with HTML, CSS, and JavaScript for GitHub Pages. No checkout or sales flow.

## Preview

Open `index.html` through a local static server. The page opens in Spanish; the ES / EN control switches to English. Mobile navigation opens from the menu button.

## Social sharing\n\nThe Open Graph and Twitter preview metadata is Spanish-first, with the clean Pages root URL as canonical.\n\n## Central settings

Edit `site-config.js` to change the business name, full business name and brand line, location, email, WhatsApp number, or social URLs. For WhatsApp, use the international number with digits only.

## Before launch

- Add contact and social URLs in `site-config.js` when ready.
- Replace inspiration photos with the business’s own real service photos when available.
- Add client-approved testimonials and real social posts when ready.

## Pages and gallery

- `index.html` is the home page, with a short photo preview.
- `gallery.html` shows the fuller photo gallery.
- `contact.html` gathers the contact and social links.
- Edit `site-config.js` to add the official social URLs and contact details. To add or replace a gallery photo, copy a compressed image into `assets/photos/` and update the `galleryPhotos` list in `site-config.js`. Gallery images are marked as inspiration until replaced by Elegguacita's own client-approved photos.
